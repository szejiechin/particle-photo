# Security Policy

## Supported version

Only the latest revision of the prototype is maintained.

## Reporting a vulnerability

Please do not publish credentials, private images, exploit details, or personal
information in a public issue. Use GitHub's private vulnerability reporting
feature when it is available for this repository.

This is a non-commercial, just-for-fun prototype. Reports are reviewed on a
best-effort basis, and no response-time guarantee is provided.
