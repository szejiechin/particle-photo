# Prototype RC Known Issues

- The installer is not code-signed, so Windows SmartScreen may display a warning.
- Visual recognizability and perceived foreground/background separation still require five independent human reviewers.
- Clean-machine install, offline launch and uninstall must be verified on a second Windows machine without Node.js.
- The Prototype intentionally has no camera, gesture control, project saving, export, undo/redo, cloud features or language switching.
