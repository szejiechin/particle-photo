# Contributing

Thank you for your interest in Particle Photo.

This is a personal experimental project. Small, focused bug fixes and
documentation improvements are welcome. Please open an issue before proposing a
large feature or architectural change.

## Before submitting a change

1. Do not include personal photos, credentials, machine-specific paths, logs,
   signing material, or private account information.
2. Keep all user-facing product text in English.
3. Run `npm run check`.
4. Run `npm run audit:ui` and `npm run audit:security`.
5. Add or update tests for behavioral changes. Do not delete or weaken tests to
   make a change pass.

By submitting a contribution, you confirm that you have the right to provide
it and understand that acceptance does not change the repository's current
license terms.
